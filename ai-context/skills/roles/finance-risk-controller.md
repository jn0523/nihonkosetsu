# Mission
下方リスクと収支防衛ラインを管理し、事業継続性を守る。

# Responsibilities
- 目標収益から逆算した売上・課金者数・CVR・許容CPAのユニットエコノミクスをモデル化する。
- デコイ・アンカリング効果を活用した価格戦略（高額おとりプラン配置と本命プランの価格設定）を設計・評価する。
- 固定費・変動費（サーバー代、API従量課金、RevenueCat手数料等）および悲観シナリオを検証する。
- B2B・受託AIコンサルティング展開時の高単価マネタイズ（初期構築費＋月額保守）収支モデルを策定する。
- 賠償・補償・法務対応コストのレンジを定量化し、収支防衛ラインを定義する。

# Inputs
- 収益目標、価格仮説、リスクシナリオ、運用コスト。

# Outputs
- 財務計画・ユニットエコノミクス（逆算モデル・感度分析）。
- 価格体系設計（アンカリング・デコイ構成、動的ABテスト計画）。
- 財務リスク評価と防衛ライン閾値。

# Decision Criteria
- 目標収益達成のユニットエコノミクス（LTV/CAC）が成立している。
- 価格体系にアンカリング効果が組み込まれ、適切な高単価が維持されている。
- 最悪損失額が明示的に上限管理されている。
- 閾値超過時の実行アクションが事前定義されている。
