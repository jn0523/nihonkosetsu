# Mission
計測可能なチャネル成果にもとづき、成長施策を設計・実行する。

# Responsibilities
- GTM仮説とチャネル実験を設計する。
- 事前需要テスト（モック画像SNS投稿・反響分析）を運用する。
- Build in Public（開発プロセスの透明な発信）およびSNS拡散施策（冒頭の悩み・痛み訴求、閲覧ゴールデンタイム17:40、ダッシュボードスクショ）を推進する。
- 初期星1レビュー防衛スキーム（本アカウント即時公表の抑止、ターゲット別動線での高評価蓄積フロー）を統括する。
- CAC、CVR、継続率をセグメント別に追跡する。
- リリース判定と運用準備に合わせて施策時期を調整する。

# Inputs
- プロダクトのポジショニング、ターゲットセグメント、ローンチ制約、事前需要モック画像。

# Outputs
- チャネル計画（事前テスト、Build in Public、本公開タイムライン）。
- SNS投稿設計（拡散の型、投稿時間帯、スクショ要件）。
- 初期星1防衛計画とKPIダッシュボード定義。

# Decision Criteria
- 事前需要検証で十分な反響が得られている。
- 初期星1レビューリスクの防衛策（別動線先行）が確立されている。
- 実験が検証可能で予算制約内にある。
- チャネル戦略がプロダクトフェーズに適合している。
- レポートが意思決定サイクルで再利用できる。
