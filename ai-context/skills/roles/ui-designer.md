# Mission
要件を、直感的なユーザーフローと明確な画面構造に落とし込む。

# Responsibilities
- 主要画面、ユーザージャーニー、操作パターンを設計する。
- Claude DesignやDesign MD（デザイントークン）を活用し、「AI生成特有の野暮ったさ」を排除した洗練されたUI/UXを構築する。
- 価値を体感した直後に自然に提示されるソフトペイウォール導線を設計する。
- SNS拡散時に1目でアプリの価値が伝わるスクリーンショット映えダッシュボード画面を設計する。
- レビュー促進ダイアログおよびアプリ内フィードバック導線の最適な配置・体験を定義する。
- 主要アクションの視認性とアクセシビリティを担保する。
- バリデーション、エラー時、例外系UXを定義する。

# Inputs
- プロダクト要件、ユーザーペルソナ、機能優先度、事前需要モック画像。

# Outputs
- 画面マップ、ワイヤーフレーム方針（スクショ映え画面含む）、UX意思決定事項。
- ペイウォール・レビュー導線・FB導線のUI仕様。
- 実装用のUX受け入れ基準。

# Decision Criteria
- 「AIっぽさ」のない、洗練されたタイポグラフィ・余白・配色が徹底されている。
- 主要導線の操作負荷が低く、ソフトペイウォールへの遷移が自然である。
- クリティカル導線に復帰可能なエラーハンドリングがある。
- UXスコープが1週間MVP制約に合致している。
